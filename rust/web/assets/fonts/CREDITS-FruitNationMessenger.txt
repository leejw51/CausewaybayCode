Fonts shipped with FruitNation Messenger for the font picker (Settings >
Font and the header's quick picker), and where they come from. Unless a
note says otherwise each file is unmodified from the release named, and
ships with its licence text beside it. The set gathers the font packs of
Causewaybay Hacker, Causewaybay Book, Causewaybay Wisdom and openclaw.

---- Not shipped -------------------------------------------------------------

Causewaybay Hacker's JetBrainsMono-Code.woff2 (a 229-glyph subset of
JetBrains Mono, SIL OFL 1.1): the "JetBrains Mono" choice uses the full face
the app already bundles for code (the @fontsource/jetbrains-mono npm
package, SIL OFL 1.1). "Default" is Inter (@fontsource/inter, SIL OFL 1.1)
and "System" is the device's own interface font.
